# PIF device presets

The default PIF and selectable catalog are limited to numbered Pixel 7-family and older models. Pixel Fold, Pixel Tablet, Pixel 8 and newer models are not included.

The daily updater publishes only when it can fetch an eligible stable OTA link and matching stable-shaped metadata. If Google's stable OTA page presents terms instead of download links, it leaves the existing PIF and catalog unchanged rather than substituting a beta build. Existing preset fingerprints may be historical; selecting one does not guarantee a Play Integrity verdict. The app's Play Integrity screen includes a device fingerprint picker; applying a preset turns off automatic PIF updates so a later refresh will not replace the manual choice.
